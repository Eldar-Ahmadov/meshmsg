01 / PIN FIRST

Ready before it’s announced.

The sender stores and pins the file before it broadcasts the offer, so any peer that sees the offer can fetch it immediately.

02 / OPT IN

Offers are not downloads.

Every peer gets the offer. Bytes move only after an explicit download with an output path that doesn’t exist yet. Nothing is ever overwritten.

03 / VERIFY

Trust the hash, not the pipe.

The BLAKE3 hash is part of the signed offer. Each block is checked against it as it streams; one bad block fails the whole download.

MESHMSG ATTACHMENTS iroh-gossip offer · iroh-blobs transfer · BLAKE3 verified streaming

Faithful to meshmsg’s download order: signed-offer check, no-clobber path check, size limit, local-copy check, provider connection, verified size, free space, stream, pin, then hard-link install. Not shown: quotas, retention, directory tar snapshots and retries. Offers are reusable capabilities: anyone who holds one can fetch the plaintext from the provider, so treat them like a link to the file.
